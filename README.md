# Client GUI (Fabric 1.21.1, loader 0.16.14)

Press **M** for the click GUI. Left-click a module to toggle it, right-click to open its settings,
drag the panel headers to move them. Settings save to `config/clientgui.json`.

Modules: Auto Safe Anchor, Auto Mace, Trigger Bot, Auto Hit Crystal, Pearl Catch (right-click with a sword).
Theme: accent color + opacity under Client > GUI Theme.

Build: push to GitHub (workflow included) or run `gradle build` with Java 21. Needs Fabric API 0.115.0+1.21.1 or newer.
Use only where this kind of automation is allowed.
